Rules: where files go

One rule per line, the first that fits wins. A file whose older revision is already filed always goes next to it.
pdf, dwf -> Drawings\PDF  (by file type) · contains: clash -> Coordination\Clash reports · starts: T1- -> Tower 1\{EXT}
You can use {EXT}, {REV}, {TOWER} and {TYPO} in the folder (Tower / Typology come from the Drawing Register).
